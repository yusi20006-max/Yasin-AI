# FeedBridge Vision

FeedBridge aims to become a universal content automation platform.

## Goals

- Receive content from multiple sources
- Process content using AI
- Remove duplicates
- Translate
- Summarize
- Schedule publication
- Publish to multiple destinations

## Supported Sources

- Telegram (via a vendored fetcher component, ported from OpenFeed — no separate service required)
- RSS
- Twitter/X
- YouTube

## Supported Destinations

- Eitaa
- Telegram
- Webhooks
- REST API

## Future

FeedBridge should evolve into a plugin-based platform where new sources and publishers can be added without changing the core system.
